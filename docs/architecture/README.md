# Architecture

This folder is the source of truth for the MP4 transcription service architecture.

- [System architecture](system-architecture.md) — components, trust boundaries, and data flow.
- [Job lifecycle](job-lifecycle.md) — states, artefacts, recovery, and human review gate.

The service remains a private, on-demand CPU transcription worker. It is not a knowledge base, RAG system, video platform, or persistent application service.
